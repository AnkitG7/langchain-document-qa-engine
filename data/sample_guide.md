# System Architecture Guide

## Overview
This document outlines the architectural layers of the DocMind document processing system.

## Ingestion Layer
The ingestion layer is responsible for parsing heterogeneous document formats:
- **PDF Documents**: Extracted page by page, preserving page numbering in metadata.
- **CSV Spreadsheets**: Converted into row-wise structured narratives with header preservation.
- **Web Pages**: Scraped and sanitized to remove script tags, headers, and navigation footers.

### Chunking Strategies
We provide multiple chunking techniques:
1. **Recursive Chunking**: Splits by paragraphs first, then lines, then spaces.
2. **Token-Budget Chunking**: Ensures chunks fit precisely inside token budgets.
3. **Markdown Header Chunking**: Preserves markdown section hierarchies.

## Retrieval Layer
The vector store indexes all chunks with embeddings generated by dedicated models like `nomic-embed-text`.
Querying supports similarity search, MMR (Maximal Marginal Relevance), and threshold filtering.
